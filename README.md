# ❤️ Saathi — AI Heart Health Assistant

Saathi is a simple AI-based project that helps users understand possible heart-related risks based on symptoms.  
It supports both voice input and a web interface, and gives an easy-to-understand explanation.

---

## ✨ What it does

- Takes symptoms (voice or text)
- Converts them into medical features
- Uses a trained ML model to predict risk
- Explains the result in simple language using AI

---

## 🧠 Tech used

- Python + Flask (backend)
- Random Forest (ML model)
- OpenRouter API (for explanation)
- SpeechRecognition + pyttsx3 (voice)

---

## 📊 Dataset

This project uses the UCI Heart Disease dataset.
